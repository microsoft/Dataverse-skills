# Microsoft Dataverse MCP Server

Connect AI agents to Microsoft Dataverse to query, create, and manage
tables, records, and solutions. The local stdio MCP server is distributed
through the `@microsoft/dataverse` npm package.

For prerequisites, authentication, and setup instructions, see
[Connect using the local proxy on Microsoft Learn](https://learn.microsoft.com/power-apps/maker/data-platform/data-platform-mcp-other-clients#connect-using-the-local-proxy).
